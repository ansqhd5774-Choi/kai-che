# 2D Wizard Asset Selection R3

Selection date: 2026-10-07

## Saved candidates

1. Evil Wizard 3 — LuizMelo
2. EVil Wizard 2 — LuizMelo
3. Wizard Pack — LuizMelo

## Selection policy

These three are retained as the current top candidates because they have:
- explicit commercial-use permission;
- CC0 licensing;
- non-AI source declaration;
- required combat animation coverage;
- multiple attack/hit/death frames;
- an established creator ecosystem with other fantasy characters/creatures.

## Important gate

These are CANDIDATES, not the final player character.

Final adoption requires:
1. actual image/sprite-sheet visual inspection;
2. 100% / 50% / 25% scale readability check;
3. Unity animation playback;
4. 96 px-class mobile display test;
5. game-camera compatibility check;
6. 30-second movement and 10-attack real-device test.

## Ranking before Unity device test

- Evil Wizard 3: strongest animation coverage, but 33x53 native size requires readability validation.
- EVil Wizard 2: strongest balanced combat candidate.
- Wizard Pack: strong hero silhouette and 58x86 character dimensions, but fewer Idle frames.

The old 3D Kai-Che character/environment line is not part of this selection.
