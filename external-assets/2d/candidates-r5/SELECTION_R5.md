# Kai-Che 2D Mage Candidate Selection R5

Date: 2026-10-07
Status: ACTIVE

## Non-negotiable rule
Playable mage art must support native 8-direction facing:
N, NE, E, SE, S, SW, W, NW.

Side-view and 4-direction assets are rejected.

## Current top 3
1. Chibi Mage HD — Antahonist
2. Mage Hero Complete Set — GegX
3. MAGE Colour Variants — GegX

## Why the old three were rejected
Wizard Pack, Evil Wizard 2 and Evil Wizard 3 are side-view assets. They are archived only as references and must not be used as the controllable player character.

## Final-adoption gate
A candidate is not FINAL until:
- actual downloaded files are legally available;
- all 8 direction folders/rows are inspected;
- Idle >= 4 frames each direction;
- Move >= 6 frames each direction;
- Attack/Cast >= 6 frames each direction;
- Hit >= 2 frames each direction;
- Death >= 4 frames each direction;
- feet/pivot drift <= 3 px, target <= 2 px;
- 96 px mobile readability passes;
- Unity 8-direction movement/cast/hit/death smoke passes;
- real-device test passes.

## Important
No paid asset has been purchased.
No third-party binary with redistribution restrictions has been committed.
This folder stores only evaluation metadata and source references.
