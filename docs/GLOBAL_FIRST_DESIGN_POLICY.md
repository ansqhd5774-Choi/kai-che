# Global-First Design Policy

Status: ACTIVE

## Core rule
The main game must be fully playable without understanding any natural language.

## Core information channels
- icons
- shapes
- quantity
- motion
- timing
- spatial relationships
- learned abstract symbols

## Natural language
Natural-language ability is not part of the mandatory core loop.

Do not rename symbol recognition as language ability. They are different abilities.

If language training is added later, it must be an optional localized mode built on the same core mechanics.

## Priority
1. Global accessibility
2. Simple universal controls
3. Deep reasoning
4. Cognitive coverage
5. Optional localized language mode

## R3 consequence
R3 candidates must remain solvable if all readable text is removed from the playfield.
